Terms of Service

Lore Keeper is a Discord bot that saves a copy of a roleplay server's lore channels so members can search them and server managers can export them. By adding the bot to a server or using its commands, you agree to these terms.

What the bot does

A member with the Manage Server permission picks the channels, forums, categories or threads to archive. The bot reads those places, keeps them up to date as people post, edit and delete, and answers the /lore and /loreadmin commands.

Who may use it

  • You must follow the Discord Terms of Service and Community Guidelines.
  • Only people with Manage Server should add the bot or choose what it archives. Do that only in servers you are allowed to manage.
  • Do not use the bot to harass anyone, to collect other people's information for purposes unrelated to the server, or to attempt to break or overload it.

Your content

Everything the bot saves was written by your server's members, and it stays theirs. The bot only keeps a copy for the server's use. Server managers are responsible for telling their members that the chosen channels are archived.

Availability

The bot is run by an individual on a best-effort basis. It may be offline, change, or be shut down at any time without notice, and features may be added or removed. Export your archive if you want to keep a copy.

No warranty

The bot is provided "as is", without promises that it is error-free, that every message will be captured, or that saved data will never be lost. To the fullest extent the law allows, the operator is not liable for lost data or other damages from using it.

Removal and changes

The operator may remove the bot from any server that breaks these terms. You can remove it at any time by kicking it. These terms may be updated, and the date above shows the latest version. Continuing to use the bot means you accept the changes.

Contact

Questions or requests: contact the bot's operator through the Discord server where it is installed, or message the bot's owner on Discord.

Privacy Policy

What is saved

Only from the places a server manager chose to archive:

  • The text of messages, including embeds, forwarded messages, and the names of attached files.
  • The author's Discord user ID and display name (for proxied characters, the character's name), plus when the message was posted and edited.
  • Images and files attached to those messages, unless the operator has turned file saving off.
  • The names of the channels, threads, categories and forum tags involved.

The bot does not read direct messages, does not save voice or video, and ignores channels that were not chosen.

How it is used

The saved data is used only to run the bot: search results, statistics and exports for that server. Search results only show messages from channels the person searching can open on Discord. The data is not sold, shared with advertisers, or used to train AI models.

Where it is stored

Data is stored in a database and in files on the computer or server where the operator runs the bot. It is not sent to any other service. Exports are written to the same machine, and a server manager can receive the combined export file in Discord.

How long it is kept

  • Messages deleted on Discord are removed from the archive, including their saved files.
  • When a server manager stops archiving a place with /loreadmin untrack, everything saved from it is deleted.
  • Removing the bot from a server does not delete its archive by itself. Ask the operator to delete it.

Your choices

If you want your messages removed, delete them on Discord or ask a server manager or the operator to remove them from the archive. Contact the operator as described above to ask what is stored about you or to have it deleted.

Children

Discord requires users to be at least 13 (or the minimum age in their country). The bot is not meant for anyone younger.
